One of the most robust findings in memory research; no named replication controversy.

The Serial Position Effect

We remember the first and last items in any list far better than everything sandwiched in the middle.

Use

Useful to decide what goes first and last when you need someone to actually remember it — a list, a pitch, a set of instructions.

The serial position effect describes how well we remember something based on where it falls in a sequence. Items at the start of a list get rehearsed and stored well (the primacy effect); items at the end are still sitting in working memory when we're asked to recall (the recency effect). Everything in between gets the least attention and the worst recall.

Read the restShow less

Read a grocery list of fifteen items once, then try to recite it. You'll likely nail the first three and the last three. Item eight — the broccoli, say — vanishes, not because it mattered less, but because of where it sat in the line.
