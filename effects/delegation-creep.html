Evidence note

Names an emerging pattern of expanding reliance on automated systems, built on automation-bias and complacency research; it has not been tested as a separate phenomenon under this label.

Delegation Creep

A tool given small tasks quietly ends up making calls that actually matter.

Use

Useful to notice when a tool you trusted for small tasks has quietly started making decisions that carry real weight.

Delegation creep is the way automated tools quietly take on more responsibility than anyone signed off on. A scheduling assistant that started out proposing meeting times ends up deciding which requests get flagged as urgent and which get buried. Each step feels small, and each step has worked so far, so nobody stops to ask whether the system should be making that particular call. Automation research calls the underlying pattern automation bias: once a tool has a track record of being right, people stop double-checking it, even as its job quietly expands. The result is that decisions with real weight end up running through a system nobody ever formally approved for that.
